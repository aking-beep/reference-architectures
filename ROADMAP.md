# Reference Architectures — Roadmap

## Shipped (0.2)
- 20 architectures harvested from ARC Google Drive folders and Labs products.
- Origin citations and **When not to use** on every entry.
- ASCII shape diagrams; Kinesis SVG from the DEA-C01 lesson.
- Searchable, filterable browse UI.
- Read-only JSON API + open content repo (`npm run sync-content`).
- Per-architecture detail pages with source links.
- CLI search (`npm run catalog`).

## Next
- Interactive Mermaid diagrams for entries that are still ASCII-only.
- Cost and operational-complexity ratings.
- Terraform / IaC starter snippets for the AWS-shaped entries (Kinesis, Bedrock pipeline).

## Later
- Cloud-specific variants (GCP, Azure) only where ARC has actually run them.
- Versioned entries + changelog per architecture.
- A Well-Architected overlay that maps entries onto the six pillars.
